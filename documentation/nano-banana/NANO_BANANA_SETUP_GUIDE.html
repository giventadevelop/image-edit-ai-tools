1. Quick start (3 steps)

🚀 Run the project and open the tool
  1. Create .env.local at the project root with your Gemini key (see section 3).
  2. Start the dev server from the repo root (PowerShell or terminal):
    Recommended start command
    npm run dev -- -p 3002
    Windows Single-Line:
    npm run dev -- -p 3002
    ⚠️ Port flag syntax: Use npm run dev -- -p 3002 (note the -- before -p). npm run dev --p -3002 is not valid and will not set the port correctly.
  3. Open the prompt builder in your browser:
    • Primary: http://localhost:3002/ (Next.js React UI)
    • Fallback: http://localhost:3002/nano-banana.html (static HTML, no React)
✅ You do not need Clerk keys, tenant IDs, or backend API URLs for the Nano Banana workflow. Only GEMINI_API_KEY is required.

2. Overview

The Nano Banana prompt builder is served as the default home page of this Next.js app (src/app/page.tsx). It lets you attach reference images, fill parameter fields (aspect ratio, dimensions, style, lighting, camera, mood, palette, subject, setting, modifications, negative prompt, variations, seed, model), edit a templated prompt + JSON with {{token}} placeholders, copy the merged output, and call Google's gemini-2.5-flash-image model via an internal API route.

The API key lives server-side only (never shipped to the browser). The page is a client component; its 🍌 Run button posts to /api/nano-banana, which forwards the request to Gemini using the key from .env.local.

ℹ️ Higgsfield / other AI editors: Paste the natural-language prompt (Base prompt / Copy customized) into Higgsfield with the reference image attached. The JSON is optional structure for this app's templates — Higgsfield mainly uses the text prompt. Use Describe image → prompt + JSON to fill both fields from a reference poster.
⚠️ Keys: This tool uses GEMINI_API_KEY only. There is no Anthropic / Claude key involved in Nano Banana or the describe/generate routes. If you also use Task Master / Claude CLI elsewhere, that would be a separate ANTHROPIC_API_KEY — not required here.

3. Environment configuration

⚙️ Required environment variable

Add the following line to .env.local at the project root:

.env.local entry
🔧 Customize Parameters:
GEMINI_API_KEY=your_key_from_aistudio_google_com
Single-line:
GEMINI_API_KEY=your_key_from_aistudio_google_com

Variables:

  • GEMINI_API_KEY — required. Server-side only. Get a free key at aistudio.google.com/apikey.
  • GEMINI_IMAGE_MODEL — optional. Overrides the default gemini-2.5-flash-image. Used by the CLI test script; the web UI has its own model selector.
⚠️ Security: .env.local is already in .gitignore — never commit your key. The key is only read from the server route (src/app/api/nano-banana/route.ts), so it is never exposed to the browser.

4. Starting the dev server (port 3002)

📋 Start command

Use this command to run the Next.js dev server on port 3002:

Dev server — custom port
🔧 Customize Parameters:
npm run dev -- -p 3002
Windows Single-Line:
npm run dev -- -p 3002

Alternative ways to set the port

PowerShell — environment variable
$env:PORT="3002"; npm run dev
Windows Single-Line:
$env:PORT="3002"; npm run dev
bash / git-bash — environment variable
PORT=3002 npm run dev
Single-Line:
PORT=3002 npm run dev

Making it permanent (optional)

To avoid retyping the port flag, add a script to package.json:

package.json → scripts
"dev:3002": "next dev --webpack -p 3002"
Single-Line:
"dev:3002": "next dev --webpack -p 3002"

Then start the server with:

Shorthand (after the package.json change)
npm run dev:3002
Single-Line:
npm run dev:3002

10. Troubleshooting

🔧 Common issues and fixes

Clerk error on / — useAuth can only be used within ClerkProvider

Symptom: GET / 500 with Clerk useAuth error in ClerkSyncUrlCleanup.tsx.

Cause: Clerk satellite cleanup components ran even when NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY was unset.

Fix (already in repo): src/app/layout.tsx only mounts Clerk sync components inside ClerkProvider when a Clerk key exists. /api/nano-banana is a public route in src/middleware.ts.

✅ For image-tools use: Omit all Clerk env vars and restart npm run dev.

React hydration mismatch — fdprocessedid on buttons/inputs

Symptom: Console warning: “A tree hydrated but some attributes… didn't match” with fdprocessedid="…" on form controls.

Cause: Browser extensions (often Norton Safe Web, password managers, or form fillers) inject attributes before React hydrates. Not an app bug.

Fixes:

  • Built-in: src/app/page.tsx shows a brief “Loading…” shell until client mount, then renders the form (avoids SSR/hydration on inputs).
  • Workaround: Use http://localhost:3002/nano-banana.html (static HTML, no React).
  • Extension: Disable Norton/form extensions for localhost, or test in a private/incognito window.

pip.exe blocked by Norton (Python image scripts)

Symptom: pip install pillow or similar blocked by antivirus.

Workaround: Use ffmpeg scripts instead (e.g. hero collage split). For the web UI, only npm run dev and GEMINI_API_KEY are needed — no Python.

Port already in use

If port 3000 is busy, Next.js may pick another port (e.g. 3002). Check the terminal line Local: http://localhost:XXXX and use that URL, or force a port with npm run dev -- -p 3002.

API returns 401 or “GEMINI_API_KEY is not set”

  • Add GEMINI_API_KEY=… to .env.local and restart the dev server.
  • Get a key at aistudio.google.com/apikey.

11. Restoring the previous home page

↩️ If you want the old home back

The original home (a one-line renderer for CircleHome6Page) was saved as src/app/page.circle-home.tsx.bak. To restore:

Swap back (bash / git-bash)
mv src/app/page.tsx src/app/page.nano-banana.tsx.bak; mv src/app/page.circle-home.tsx.bak src/app/page.tsx
Single-Line:
mv src/app/page.tsx src/app/page.nano-banana.tsx.bak; mv src/app/page.circle-home.tsx.bak src/app/page.tsx
