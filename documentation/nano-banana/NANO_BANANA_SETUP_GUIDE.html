1. Overview

The Nano Banana prompt builder is served as the default home page of this Next.js app (src/app/page.tsx). It lets you attach reference images, fill parameter fields (aspect ratio, dimensions, style, lighting, camera, mood, palette, subject, setting, modifications, negative prompt, variations, seed, model), edit a templated prompt + JSON with {{token}} placeholders, copy the merged output, and call Google's gemini-2.5-flash-image model via an internal API route.

The API key lives server-side only (never shipped to the browser). The page is a client component; its 🍌 Run button posts to /api/nano-banana, which forwards the request to Gemini using the key from .env.local.

2. Environment configuration

⚙️ Required environment variable

Add the following line to .env.local at the project root:

.env.local entry
🔧 Customize Parameters:
GEMINI_API_KEY=your_key_from_aistudio_google_com
Single-line:
GEMINI_API_KEY=your_key_from_aistudio_google_com

Variables:

  • GEMINI_API_KEY — required. Server-side only. Get a free key at aistudio.google.com/apikey.
  • GEMINI_IMAGE_MODEL — optional. Overrides the default gemini-2.5-flash-image. Used by the CLI test script; the web UI has its own model selector.
⚠️ Security: .env.local is already in .gitignore — never commit your key. The key is only read from the server route (src/app/api/nano-banana/route.ts), so it is never exposed to the browser.

3. Starting the dev server (port 3002)

📋 Start command

Use this command to run the Next.js dev server on port 3002:

Dev server — custom port
🔧 Customize Parameters:
npm run dev -- -p 3002
Windows Single-Line:
npm run dev -- -p 3002

Alternative ways to set the port

PowerShell — environment variable
$env:PORT="3002"; npm run dev
Windows Single-Line:
$env:PORT="3002"; npm run dev
bash / git-bash — environment variable
PORT=3002 npm run dev
Single-Line:
PORT=3002 npm run dev

Making it permanent (optional)

To avoid retyping the port flag, add a script to package.json:

package.json → scripts
"dev:3002": "next dev --webpack -p 3002"
Single-Line:
"dev:3002": "next dev --webpack -p 3002"

Then start the server with:

Shorthand (after the package.json change)
npm run dev:3002
Single-Line:
npm run dev:3002

5. API endpoint reference

🔌 POST /api/nano-banana

Source: src/app/api/nano-banana/route.ts

Request body

FieldTypeRequiredDescription
action"generate" | "describe"✅generate creates/edits an image; describe returns structured JSON for an input image
promptstring✅ for generateFinal prompt (after token substitution)
jsonstring—Optional JSON spec appended to the prompt
imagesArray<{ mimeType, data }>✅ for describeBase64-encoded reference images (no data: prefix)
modelstring—Defaults to gemini-2.5-flash-image for generate, gemini-2.5-flash for describe

Response body (success)

FieldTypeDescription
actionstringEchoed back
modelstringModel the request was sent to
elapsedMsnumberRound-trip time to Gemini
imagesArray<{ mimeType, data }>Generated image bytes (base64)
textstringAny text part of the model response

6. Standalone CLI test script

🧪 Test the Gemini key without the UI

A Node script exists at scripts/nano-banana-test.mjs for testing the API key end-to-end from the terminal:

Smoke test (edit an image)
🔧 Customize Parameters:
node scripts/nano-banana-test.mjs
Windows Single-Line:
node scripts/nano-banana-test.mjs

Output images are written to nano-banana-output/ in the project root with a timestamped filename.

7. Restoring the previous home page

↩️ If you want the old home back

The original home (a one-line renderer for CircleHome6Page) was saved as src/app/page.circle-home.tsx.bak. To restore:

Swap back (bash / git-bash)
mv src/app/page.tsx src/app/page.nano-banana.tsx.bak; mv src/app/page.circle-home.tsx.bak src/app/page.tsx
Single-Line:
mv src/app/page.tsx src/app/page.nano-banana.tsx.bak; mv src/app/page.circle-home.tsx.bak src/app/page.tsx
